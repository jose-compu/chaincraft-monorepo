Feature parity

A feature is done when Python, Rust, and TypeScript make the same accept and reject decisions and emit the same bytes. SPEC/features.yaml is the registry. tools/parity_check.py fails the build when a manifest disagrees with it.

TypeScript is 31 implemented features plus one exemption. Browsers have no raw UDP socket, and a Node-only UDP path would not be the same capability. UDP is optional at Level 0 and is negotiated in ctl.hello, so a TypeScript node still speaks the protocol over TCP.
