Build on the three cores

1.0.0 is the tree on main. Each language exposes the same envelope: a type, a payload, and an id that is the SHA-256 of the canonical payload.

Python

cd python
pip install -e ".[dev]"
python -m pytest tests/ -v
from chaincraft_core import Envelope, encode_frame

env = Envelope.build("app.counter", {"by": "alice", "delta": 1})
print(env.id)
frame = encode_frame(env.to_bytes())

Rust

cd rust
cargo test --all-features
let env = Envelope::build("app.counter", json!({"by": "alice", "delta": 1}), None)?;
println!("{}", env.id);

TypeScript

cd typescript
npm install
npm test
import { Envelope, encodeFrame } from "@chaincraft/core";

const env = Envelope.build("app.counter", { by: "alice", delta: 1 });
const frame = encodeFrame(env.toBytes());

Prove the three agree

python3 conformance/run_all.py
python3 conformance/runner/run_interop.py
python3 tools/parity_check.py --summary

The interop runner connects one node of each language and checks that an application message from each sender arrives at the other two with the same payload digest.
